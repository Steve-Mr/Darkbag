# 色温（CCT）处理建议 —— 基于本机实测与两端标定

> 背景：`b4631444` 的 `SensorCalibrationHelper.computeRenderCcm` 用
> `cct = 2000 + 3500 × (ASN_B / ASN_R)` 估计色温再算双光源插值权重。
> 本文用**你已有的 DNG 样张 + 本机平台标定矩阵**给出诊断、可直接落地的算法、以及验证清单。
> 只读分析；脚本 `.tmp/verify/*.py`。

---

## 1. 现状诊断：方法不成立，但本场景误差不大

```kotlin
// SensorCalibrationHelper.kt:42-52
val ratio = wbB / wbR                 // = ASN_B / ASN_R
val cct = 2000f + ratio * 3500f       // ← 经验线性映射，两个常数无物理依据
val weight = ((mCur - m2) / (m1 - m2)).coerceIn(0f, 1f)
```

**问题有两层**：

1. **`ASN_B/ASN_R` 与 CCT 的关系是传感器相关的**——同一个 R/B 比在不同传感器上对应不同色温；`2000/3500` 这两个常数只对某一类传感器偶然成立，换机型/换传感器模式即失准。
2. **本场景被 clamp 饱和**：`ASN=(0.4313,1,0.6928)` → ratio 1.606 → cct **7622K** → mired 131 → `weight=1.115` → **clamp 到 1.0 ⇒ 只用 FM1(D65)**，双光源插值从未生效。

**但实测影响有限**（同一张 DNG，只改权重）：

| 权重 w | 与 w=0.83 的平均通道差 (8bit) | 最大 |
|---|---|---|
| 0.500 | 0.61 | 19.0 |
| **0.906（本场景正确值）** | — | — |
| 0.967 | 0.25 | 7.9 |
| **1.000（当前 clamp）** | **0.32** | **9.8** |

⇒ 平均 0.3/255、峰值 ~10/255（高饱和色更明显）。**属"方法学错误 + 中等可见度"，不是阻断项**，建议排在灰卡验证之后做。

## 2. 推荐算法：两点定标 + 阻尼不动点（实测收敛）

### 2.1 用设备自身标定取两个锚点（关键）

DNG 模型里，标定矩阵把**标定光源的白点**映射为该光源下的**相机中性**：

```
n_A  = CM_A · XYZ(Standard Light A)      # 2856K 的相机中性
n_D  = CM_D · XYZ(D65)                   # 6504K 的相机中性
（各自归一化到 G=1，与 AsShotNeutral 同口径）
```

本机实测锚点：`q_A = n_A.R/n_A.B = 4.679`，`q_D = n_D.R/n_D.B = 0.482`（差近 10×，符合钨丝/日光的物理直觉）。

> ⚠️ **不要假设 `CalibrationIlluminant1 = D65`**：本机平台是 `1=D65, 2=Light A`，而 GCam 的 DNG 恰好相反（`1=Light A, 2=D65`）。
> 你们的代码已按 `calibrationIlluminant1/2` 取温度 ✅，这点是对的，继续保持。

### 2.2 两步求权重

```kotlin
// ① 初值：把 ASN 的 R/B 比投影到两锚点之间（免迭代，稳健）
val q  = asn[0] / asn[2]
val qA = nA[0] / nA[2]
val qD = nD[0] / nD[2]
var w  = ((q - qA) / (qD - qA)).coerceIn(0f, 1f)     // 0=Light A, 1=D65

// ② 自洽迭代（DNG 规范做法）：矩阵按 mired 插值 → 反推白点 → 重算权重
val mirA = 1e6f / 2856f; val mirD = 1e6f / 6504f
repeat(5) {
    val cm = lerp(cmA, cmD, w)
    val wxyz = solve3x3(cm, asn)                     // 插值矩阵下的场景白
    val cct  = mccamy(wxyz)                          // 2856–6504K 内有效
    val wt   = ((1e6f / cct - mirA) / (mirD - mirA)).coerceIn(0f, 1f)
    if (abs(wt - w) < 1e-4f) return@repeat
    w += 0.5f * (wt - w)                             // ★ 阻尼 0.5 必需，否则收敛慢/振荡
}
```

**实测收敛行为**（22:08 那张）：`w: 0.5 → 0.75 → 0.875 → 0.906 → 0.906`（5 步），收敛值 **w=0.906、CCT≈5804K**；
仅用①的投影初值是 0.967（≈6236K）——两者差异即"矩阵↔白点"非线性带来的近似误差，建议以②为准。

### 2.3 本批样张的正确值（可直接对照）

| 文件 | q=R/B | **w（收敛）** | **CCT** | tint |
|---|---|---|---|---|
| 21:34 (ISO100) | 0.628 | 0.902 | 5781K | 1.004 |
| 21:35 (ISO987) | 0.670 | 0.879 | 5635K | 1.028 |
| 22:08 (ISO100) | 0.623 | **0.906** | **5804K** | 1.008 |
| 22:12 (ISO665) | 0.683 | 0.872 | 5592K | 1.035 |

⇒ 这些场景都是**约 5600–5800K 的冷白荧光**（与预览里偏蓝白的灯光一致），正确权重 0.87–0.91，而当前实现取 1.00。

## 3. 顺带建议：把"色偏（tint）"也量化出来

单靠 CCT 无法表达荧光/LED 常有的**离轨**偏移，建议用绿平衡比值：

```
b(n) = n.G / sqrt(n.R · n.B)
tint = b(ASN) / [ (1-w)·b(n_A) + w·b(n_D) ]      // >1 偏绿，<1 偏品红
```

本批样张：**1.002 / 1.008 / 1.028 / 1.035** ⇒ 场景比黑体轨迹**偏绿最多 +3.5%**——这正是"荧光灯下发绿"的定量形式。
建议把它写进日志（或未来的 WB/Tint 手动项的第二个轴）；注意：**tint 不影响中性**（FM 的归一化已保证中性 ✓），只影响非中性色的再现。

## 4. 验证清单（一次拍完，判据明确）

### 4.1 该机型的期望值（由两端标定推出，可直接照抄做断言）

| 光源 | CCT | 期望 w | 期望 ASN（R, 1, B） | 期望 R/B |
|---|---|---|---|---|
| Standard Light A（钨丝） | 2856K | 0.000 | (1.229, 1, 0.263) | 4.679 |
| 暖白 LED | ≈3500K | 0.328 | (0.936, 1, 0.445) | 2.102 |
| 中性荧光 | ≈4100K | 0.541 | (0.754, 1, 0.559) | 1.349 |
| D50 | 5003K | 0.765 | (0.569, 1, 0.674) | 0.843 |
| D65（正午日光） | 6504K | 1.000 | (0.382, 1, 0.791) | 0.482 |

### 4.2 拍摄与判据

拍 **灰卡/白墙** 在 **钨丝（或暖光）** 与 **日光** 两种光源下各一组（HDR+，DNG+JPEG），判据：

1. `R/G ÷ ASN`、`B/G ÷ ASN` = **1.00 ± 0.02**（脚本 `wall_lsc_test.py`）；
2. 日志里的 `w` 与 §4.1 期望值差 **<0.10**（若钨丝下 w 仍≈1.0 ⇒ 插值没生效）；
3. 与 GCam 同场景同亮度对比 **ΔE00 最小**；
4. `tint` 与目视一致（钨丝约 1.00、荧光可能 1.02–1.05）。

## 5. 已知局限（建议写进代码注释）

| 局限 | 说明 | 对策 |
|---|---|---|
| 两端光源都在普朗克轨迹附近 | 荧光/LED 常**离轨**，CCT 描述不了 tint | 用 §3 的 tint 轴补充；中性由 ASN 保证 ✓ |
| 混合光源 | 单 CCT 不可描述（窗光 + 灯光） | 以 `CONTROL_AWB_STATE == CONVERGED` 为可信条件，否则**回退 as-shot CCM** |
| McCamy 适用范围 | 2856–6504K 之外误差增大 | 超范围改用 Robertson 法或查表 |
| 权重只影响非中性色 | 中性由 `FM·(1,1,1)=XYZ(D50)` 保证 ✅ | 因此优先级为**中**，不是阻断 |
| 手动 WB/Tint | 若将来加滑杆，两个轴天然对应 mired 与 tint | 直接把滑杆映射到 `w` 与 tint，物理一致 |
