## 1. 为什么"post-demosaic LSC"会让环带更明显

按数据流逐条对应（都能在 `hdrplus_pipeline_generator.cpp` 的 PR 版本里核到）：

1. **粗网格双线性插值的 C¹ 不连续被直接输出。**
   Camera2 的 LSC map 是**粗网格**（常见 17×13 / 33×25）。`sample_lsc()` 做双线性插值：
   网格内部光滑，但**格线处一阶导数不连续**。Bayer 域施加时，后面还有去马赛克插值（5×5）会把这些折线"抹"一遍；
   搬到 demosaic 之后，**没有任何后续平滑**，折线直接进入输出 → 在亮度梯度大的区域（灯周围）成为**可见的同心色带**。
2. **三个通道各自一张网格 → 色带是彩色的。**
   `gain_r = sample_lsc(0)`、`gain_g = 0.5*(ch1+ch2)`、`gain_b = sample_lsc(3)` 三者的网格值不同（color shading），
   折线位置也不同 → 亮度带变成**彩色带**（实测 B/G 振荡 ±0.2）。
3. **通道序仍未判定，误差被直接搬进 R/B。**
   本机 CFA = **BGGR**（已确认）。若设备按**物理序**填 map（`4a524839` 曾记录这种情况，对 BGGR 即 `[B, Gb, Gr, R]`），
   那么 `gain_r=ch0` 拿到的是 **B 的渐晕曲线**、`gain_b=ch3` 拿到的是 **R 的** → **径向 R/B 色偏**。
   把绿通道平均（`0.5*(ch1+ch2)`）只解决了 G1/G2 交换，**没有**解决 R/B。
4. **裁剪次序变差。** demosaic 的每个子核都用 `u16_sat` 截断；LSC 在其**之后**乘 >1 的角部增益，
   于是"先截断再放大"→ 角部/亮部二次饱和，通道间比例在饱和处被破坏（Bayer 域是"先放大再截断"，比例保留得更好）。
5. **knee 只解决色相、不解决带。**
   `apply_lsc` 里的 knee 现在是**联合比例**（`scale = compressed/max_ch` 统一乘三通道）→ ✅ 不再产生色相偏移（这点改对了），
   但它压缩的是**亮度**，所以"亮度环/暗环"仍在；而**色带的颜色**来自第 1–3 条的逐通道 LSC。

## 2. 这次改动**改对了**的部分（保留）

- 联合比例 knee（Halide 与 ColorPipe 两处）→ 消除逐通道压缩的色相偏移（我在真实 DNG 上量到的 R/G=0.822、B/G=0.745 那种高光偏色会消失）。
- `gain_g = 0.5*(ch1+ch2)` → 规避 G1/G2 交换（对 BGGR 尤其有意义）。
- 去饱和阈值除以 `eff_gain`、`BaselineExposure` 上限 4.0、色度降噪回 WB 空间、`num_passes<=0` 直通、`wb_input` 去掉 `u16_sat` —— 均正确，保留。

## 3. 建议的修法（本轮）

**首选：把 LSC 移回 Bayer 域**，并保留"两绿平均"与"联合 knee 只在显示链路"：

```cpp
// generate() 里改回：
Func black_white_level_output = black_white_level(bayer_shifted, …, cfa_pattern);
Func lsc_output = apply_lsc(black_white_level_output, w, h);   // ← Bayer 域，逐 CFA 站点
Func white_balance_output = white_balance(lsc_output, wb);     // 仍为空实现
Func lsc_then_demosaic = demosaic(lsc_output, w, h);
// knee 只留给 JPEG：ColorPipe 已有联合 knee；Halide 侧对 DNG 不压缩
```
配套三点（缺一不可）：

1. **通道序显式判定后再映射**（不要用假设）：按 §4-2 的日志判定 logical/physical；
   logical → 保持 `c_idx`（平移后 R/G1/G2/B）；physical（BGGR = `[B,Gb,Gr,R]`）→ 显式重排为 `[R,G1,G2,B]`。
   > 注意：这一步在 Bayer 域是**必须**的，因为那时是按 CFA 站点取通道；搬到 demosaic 之后只会把问题藏起来。
2. **平滑 LSC 网格**：把 `sample_lsc` 的双线性换成**双三次（bicubic/Catmull-Rom）**，或先把整张 map 上采样后做一次小半径高斯；
   更稳的做法是每通道拟合**低阶 2D 多项式**（如 3×3 项）——LSC 本质是光滑的低阶场，拟合能同时去掉网格折线与观测噪声。
   验收判据：均匀白墙的径向 R/G、B/G 波动 < ±2%。
3. **裁剪次序**：保证"先乘增益、后截断"（Bayer 域天然满足）；并确认 `black_white_level` 的 `u16_sat` 不会在暗部把负值整流（见第一轮 review 的 §3.1 机制 ②）。

**次选（如果坚持 post-demosaic）**：至少做 §3-2（网格平滑）+ §3-1（通道序），并把 LSC 放在**截断之前**的浮点域执行；
但语义上仍不推荐（去马赛克看到的是未校正数据）。

## 5. 一句话总结

`c686aaed` 把 knee 改成联合比例是**对**的（消除高光色相偏移），但把 **LSC 搬到去马赛克之后是错的方向**：
粗网格双线性 + 逐通道增益 + 未判定的通道序被直接写进输出，实测**色带强度翻倍（B/G 沿半径标准差 0.024 → 0.053）**。
**建议：LSC 回到 Bayer 域（保留两绿平均）、网格改双三次或低阶多项式拟合、通道序用日志判定后显式重排、knee 只留在显示链路。**
