## 5. 平台能力取证（S0-5 裁决依据）

```
$ javap -classpath $ANDROID_SDK/platforms/android-{28,33,35}/android.jar \
        android.hardware.camera2.CameraCaptureSession | grep prepare
api28/33/35:  public abstract void prepare(android.view.Surface)
```

- `$ANDROID_SDK/sources/android-35/.../CameraCaptureSession.java:189` → `prepare(int, Surface)` 标 `@hide`（:192 为隐藏重载）。
- 同文件 `:111`：对 `maxImages=10` 的 ImageReader 调用 `prepare` 会分配全部 10 张。
- `CameraHardwareStreamController` 的 RAW reader `maxImages=8` → 12MP 下 `8 × 24MB = 192MB`（50MP RAW ≈ 800MB）。
- 结论：S0 不引入 `prepare()`；S2 在环深度确定后（`maxImages = K + 2`）重新评估。
