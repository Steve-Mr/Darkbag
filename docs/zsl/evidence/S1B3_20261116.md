## 5. 已裁决偏差

| # | 项 | 裁决 |

| 1 | `ZslProbeBottomSheet.kt` 278 行（+契约 37 行；原预算 160） | **接受**：预算修订为 ≤300（仓库硬上限）；三模式 + 状态流 + 进度 + 指标 + 剪贴板在惯用 Kotlin 下 258 行起。后续增长必须外提 formatter。 |

| 4 | pending 态：开关禁用 + Cancel 清 pending | **接受**：符合 §3.12.3「锁定，不可再次触发」，并给出取消路径。 |
| 5 | UNSUPPORTED badge 用 tertiary；Aborted 用新增 `CANCELLED` badge | **接受**：仓库无 error badge drawable；取消态已与 RUNNING 区分（`zsl_probe_badge_cancelled`）。 |

| 8 | `fragment_settings.xml` +146 | **接受**：预算修订 +160。 |
| 9 | `SettingsFragment` 实测 +25（预算 +25） | **接受**：确认对话框与回调装配恰好落在预算内。 |
| 10 | `reportStore.load()` 未做 `isApplicable`（换镜头后旧报告仍显示） | **已知**：`ZslPolicy` 侧有守卫；UI 失真项，列入 S2 前清理。 |
